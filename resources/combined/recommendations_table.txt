This table contains data on optimization plan runs. Each plan represents a group of stores and items each of which is assigned a markdown price based on markdown discount for each gate. A plan number can have multiple runs but Each unique plan run is a unique combination of plan id and create timestamp. The markdown, STR and other data and metrics can be different for the different runs and gates of a plan.
The table is extremely large (billions of records) and it is very necessary to follow these rules to query the table: query result should always be a summary, i.e., the columns selected in any query should either be aggregated or deduplicated. It could be grouped by appropriate column(s) and then these columns too could be selected. The summarization rule also applied to any sub-queries. Any query should also apply filter(s) if applicable. No query or sub-query should select all the columns in the table.
